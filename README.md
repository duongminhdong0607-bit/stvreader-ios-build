# STVReader iOS (WebView thử nghiệm)

Dự án Xcode thử nghiệm để tạo ứng dụng iPhone mở trang Sáng Tác Việt bằng WKWebView.

**Đây không phải bản STV MobileReader gốc.** Không có các tính năng native/offline của APK hoặc IPA bị thiếu dữ liệu.

GitHub Actions biên dịch ứng dụng cho iOS và tạo file IPA **chưa ký**. Cần ký file bằng Apple ID trước khi cài bằng Sideloadly.
